## About <a name = "about"></a>

Personal dashboard and stats tracker that aggregates data from media and hobby platforms including Trakt.tv, Backloggd, MyAnimeList, MyDramaList, and Last.fm — built with pure HTML5, CSS3, and zero-dependency Vanilla JavaScript.

## Getting Started <a name = "getting_started"></a>

Run locally with Node.js (zero runtime npm dependencies):

```bash
npm run dev
```

Or run with Docker:

```bash
docker compose up --build
```

Deploy directly to Vercel with zero build step (`public/` static pages + `api/*.js` Web-standard serverless functions).
